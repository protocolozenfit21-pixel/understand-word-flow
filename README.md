# Living Word Guide

PROMPT COMPLETO — APLICATIVO DE BÍBLIA GAMIFICADO E INTERATIVO

Quero criar um aplicativo PWA moderno de leitura e aprendizado da Bíblia.

O conceito do aplicativo é criar uma experiência semelhante ao Duolingo no sentido de criar hábito, progresso, desafios e constância, porém sem transformar a fé em uma competição.

O principal objetivo é resolver um problema muito comum:

Muitas pessoas querem ler a Bíblia, mas têm dificuldade em entender, não sabem por onde começar e acabam desistindo da leitura.

O aplicativo deve tornar a leitura da Bíblia mais simples, agradável, interativa e adaptada à realidade das pessoas.

🎯 OBJETIVO PRINCIPAL

Criar uma plataforma onde o usuário consiga:

Ler a Bíblia de forma simples

Entender passagens difíceis

Comparar diferentes formas de apresentação do texto

Criar o hábito diário de leitura

Participar de desafios

Acompanhar seu progresso

Receber mensagens e reflexões diárias

Fazer anotações pessoais

Salvar versículos

Aprender sobre o contexto histórico da Bíblia

Aplicar os ensinamentos bíblicos à vida atual

O aplicativo não deve parecer apenas um leitor de Bíblia tradicional.

A experiência deve ser moderna, acolhedora, intuitiva, bonita e gamificada.

🧠 CONCEITO CENTRAL

O aplicativo terá uma experiência de leitura baseada em 3 camadas.

O usuário poderá alternar entre elas facilmente durante a leitura.

📜 CAMADA 1 — TEXTO BÍBLICO

Apresentar uma versão bíblica mais próxima possível dos textos originais, utilizando traduções licenciadas ou conteúdos permitidos.

Esta camada deve ser apresentada como:

📜 Texto Bíblico

O foco é permitir que o usuário leia uma versão mais tradicional ou literal.

Importante:

Nunca modificar ou misturar explicações dentro do texto bíblico.

O texto bíblico deve permanecer visualmente separado das interpretações e reflexões.

🗣️ CAMADA 2 — LINGUAGEM ATUALIZADA

Apresentar uma versão com linguagem mais moderna e acessível.

Objetivo:

Permitir que pessoas que possuem dificuldade com linguagem antiga consigam compreender melhor o conteúdo.

Esta camada deve ser identificada como:

🗣️ Entenda de forma simples

O usuário poderá alternar facilmente entre:

📜 Texto tradicional

📖 Linguagem atual

💡 CAMADA 3 — EXPLICAÇÃO E APLICAÇÃO PARA OS DIAS ATUAIS

Esta será uma das principais funcionalidades do aplicativo.

Depois de cada passagem ou capítulo, o usuário poderá visualizar:

💡 Entenda

Uma explicação simples sobre a passagem.

📚 Contexto histórico

Explicar:

Quem escreveu

Para quem foi escrito

Em qual época aconteceu

Qual era o contexto daquele momento

Quem são os personagens envolvidos

🧠 O que significa?

Explicar a passagem de forma simples e acessível.

🌎 Como isso se aplica hoje?

Mostrar possíveis aplicações para a vida atual.

Exemplo:

📖 TEXTO BÍBLICO

"O Senhor é o meu pastor; nada me faltará."

💡 ENTENDA

A passagem apresenta Deus como alguém que guia e cuida das pessoas, assim como um pastor cuida de suas ovelhas.

🌎 APLICAÇÃO PARA HOJE

Esta passagem pode ser uma reflexão sobre confiança, direção e dependência de Deus em momentos de dificuldade.

🤔 REFLEXÃO

Em quais áreas da sua vida você sente dificuldade de confiar?

IMPORTANTE:

As explicações e reflexões devem sempre ser visualmente separadas do texto bíblico.

Nunca apresentar uma reflexão humana como se fosse parte do texto bíblico.

Quando existirem diferentes interpretações teológicas relevantes, o aplicativo poderá apresentar:

"Existem diferentes interpretações cristãs sobre esta passagem."

O aplicativo deve priorizar neutralidade e respeito entre diferentes denominações cristãs.
